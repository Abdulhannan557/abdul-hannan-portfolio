# Abdul Hannan — Personal Portfolio Website

Personal multi-page portfolio built with pure semantic **HTML5** and external **CSS3** (`css/style.css`) with zero JavaScript, created for **CSC 337 — Web Programming Languages (Assignment No. 1)** at Iqra University, Islamabad Campus (H-9).

## Pages
- `index.html` — Home: hero profile, About Me, What I Do, Technical Skills, and Career Goal.
- `hobbies.html` — Hobbies & Interests: ordered and unordered lists, online/physical game profiles, and styled tables with hover effects.
- `media.html` — Favourite Media: two-column CSS Grid layout with social inspiration posts, local & online images, and 5 embedded educational YouTube videos.
- `contact.html` — Contact: personal & university contact details, interactive HTML5 form, embedded Google Map of Iqra University H-9, and Friends & Academic Network table.

## Technical Highlights
- **Pure HTML5 & CSS3**: Semantic landmarks (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<figure>`, `<footer>`) and zero JavaScript.
- **Single External Stylesheet**: `css/style.css` using CSS custom properties, Flexbox navigation, CSS Grid multi-column layouts, sticky header positioning, table row hover effects, and responsive media queries (zero horizontal scrolling at 375px).
